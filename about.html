关于我

一个还在补基础的大二学生

不是天才，也没有大厂实习。我的方法比较笨：把想学的东西做成一个能跑起来的东西，然后被它折磨几天。

我叫陈亦航，计算机相关专业大二在读。真正开始写点有用的代码，是从想让 DeepSeek 帮我干活开始的——先是接一个 QQ 机器人，后来是本地部署编码 Agent。

这两个项目教我的东西，比任何一门课都直接：服务起不来的时候，没人替你背锅。端口被占了、插件打架了、协议对不上，这些不会出现在教材里，但会占掉你一个下午。我现在遇到问题的顺序是：复现、看日志、查文档、最小化改动，最后才动手。

我怎么做事

能跑通只是及格线。我会把启动步骤写进 README，把踩过的坑记下来，把“只在我电脑上能跑”当成 bug。课程项目里用了大量 AI 生成的代码，我的原则是：每一段都要能解释，解释不了就重写。

现在最想补的是工程基本功——测试、项目结构、网络。我不想只会调 API，我想知道请求发出去之后发生了什么。

现在

在找 AI 应用开发方向的实习，可实习 3 个月，每周 5 天。如果你在做 LLM 应用、Agent 或者内部工具，我很愿意从最基础的活干起。

01 — 时间线

事情发生的顺序

按时间倒序。没有写“从小热爱计算机”这种话，因为确实没有。

  1. 2026.11

    把作品集重写了一遍

    从零手写 HTML / CSS / JS，顺便把语义化和无障碍补上。你正在看的这个站。

  2. 2026.09 — 11

    课程项目：AI 辅助的网站开发

    Vue3 + FastAPI + MySQL。第一次正经写 REST 接口、做 JWT 登录、用 Docker Compose 部署，也是第一次意识到“能跑”和“能维护”是两件事。

  3. 2026.06

    本地部署 DSH 智能体

    用协议转发网关把编码 Agent 和 DeepSeek 接起来。最大的收获不是跑通，是学会了怎么定位“服务启动了但端口没监听”。

  4. 2026.05

    QQ 机器人上线

    NoneBot2 + NapCat。从 HTTP 适配器换成 WebSocket 长连接，加了守护进程。它在群里活了好几个月。
