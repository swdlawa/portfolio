About me

A sophomore still filling in the fundamentals

Not a prodigy, and no big-tech internship. My method is fairly dumb: turn whatever I want to learn into something that runs, then let it torment me for a few days.

I'm Ningyuan Zhou, a second-year computer science student at BIUH. I started writing code that was actually useful when I wanted DeepSeek to take chores off my hands — first a QQ bot, then a coding agent deployed on my own machine.

Those two projects taught me more than any course: when a service won't start, nobody else is carrying the can. Ports already in use, plugins fighting each other, protocols that don't line up — none of that is in a textbook, and all of it eats an afternoon. My order now is: reproduce, read the log, check the docs, make the smallest change, and only then touch the code.

How I work

Getting it to run is the passing grade, not the goal. I put the start steps in the README, write down the traps I fell into, and treat "works on my machine" as a bug. The course project leaned heavily on AI-generated code; my rule is that I have to be able to explain every block, and rewrite what I can't.

Right now I'm shoring up engineering basics — testing, project structure, networking. I don't want to be someone who only calls APIs; I want to know what happens after the request leaves.

Now

I'm looking for an AI application development internship: three months, five days a week. If you're building LLM products, agents or internal tools, I'm happy to start with the most basic work.
